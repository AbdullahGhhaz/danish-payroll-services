# Danish Payroll Services – GitHub Pages version

This is a static GitHub-ready copy of the public website content from danishpayrollservices.com, rebuilt as a simple one-page site.

## Files

- `index.html` – page structure
- `style.css` – styling

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the root of the repository.
3. In GitHub, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save.
6. GitHub will publish the site on a Pages URL.

## Before publishing

Update these items if needed:

- contact email in `index.html`
- copyright year
- wording and company details

## Notes

This version is rebuilt from the visible public website content and structure. It is not an export from the original builder/beta program.
